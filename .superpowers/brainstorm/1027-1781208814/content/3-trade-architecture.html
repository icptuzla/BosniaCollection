How should the Trading Market work on Devnet?

For trustless swaps and selling for SOL, how do we handle the transaction?

A

Smart Contract Escrow / Marketplace

Users list their NFT for trade/sale, transferring it to a program escrow. When a buyer accepts, the program automatically swaps the NFTs or sends the SOL.

B

Partial Signatures (P2P)

The first user creates and partially signs a transaction. The offer remains valid until the second user countersigns it to execute the swap directly (no escrow needed).
