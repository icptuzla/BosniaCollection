How should the Pack Opening work on Devnet?

When a user pays 0.2 SOL for a pack, how are the NFTs delivered?

A

Mint on Demand

The user's transaction mints 5 brand new NFTs directly using Metaplex Core. This is simpler to implement but the user pays the SOL rent for the new NFTs.

B

Treasury Transfer

We pre-mint the entire collection to a Treasury Wallet. When a user buys a pack, the backend/program transfers 5 random NFTs from the Treasury to the user.
